=============
User Personas
=============

Target Engineering Profiles
---------------------------

* **Security and Cryptography Engineers**: Require NIST-standardized lattice-based KEM and digital signature primitives with explicit memory zeroization and constant-time comparison guarantees.
* **FIDO2 and Identity Infrastructure Architects**: Require ``ML-DSA`` assertion signing and verification alongside hardware-backed and classical authenticators.
* **Systems and SRE Leads**: Require zero-dependency deployment against standard OS packages (OpenSSL 3.5+ and ``libsodium`` on Fedora Linux and Alpine Linux containers).
